# 基金看板

本地运行的桌面 Web 基金看板，提供持仓收益、基金自选、A股市场概览和主要市场指数展示。持仓与自选数据仅保存在当前浏览器，后端只负责转发公开行情。

## 环境要求

- Windows 10 或更高版本
- Node.js 20 或更高版本（包含 npm）

## 使用

双击根目录下的 `启动基金看板.bat`。程序启动后会自动打开：

```text
http://127.0.0.1:51888
```

保持启动窗口开启。关闭窗口后服务停止。

首次运行会自动安装依赖并构建页面，需要能够访问 npm 软件源和行情数据源。

## 使用 AI Agent 安装

将下面这句话发送给 AI Agent：

> 请从 `https://github.com/hakunamatata5893/fund-dashboard.git` 克隆基金看板项目，在 Windows 环境检查 Node.js 20 及以上版本，进入项目目录后执行 `npm run setup` 安装依赖并构建项目，然后运行 `启动基金看板.bat`，最后确认 `http://127.0.0.1:51888` 可以访问；不要读取、提交或上传任何个人持仓及备份数据。

## 数据备份

- 点击页面右上角“导入 / 导出”。
- “导出数据”会下载 JSON 备份文件。
- 导入有效备份前会展示摘要并要求确认；导入会覆盖当前浏览器中的持仓。
- 清理浏览器站点数据、更换浏览器或更换电脑前，请先导出备份。

## 开发命令

```powershell
npm run setup
npm run test
npm run typecheck
npm run build
npm start
```

开发前端运行在 `51889`，并将 `/api` 代理到本地后端 `51888`。

## 数据与隐私

- 持仓、自选和成本数据保存在浏览器 `localStorage`，不会写入项目目录或上传到服务器。
- 本仓库不包含个人持仓备份；导出的 `fund-dashboard-backup-*.json` 已设置为 Git 忽略文件。
- 公开分享、提交问题或贡献代码前，请勿附带任何个人持仓截图或备份文件。

## 行情说明

行情来自第三方公开接口，可能延迟、缺失或变更。数据仅供参考，不构成投资建议，请以基金公司、交易所及正规行情商披露为准。

指数历史行情优先读取东方财富；日经 225 与首尔综合指数在东方财富不可用时，分别使用日经指数官网与 Naver 行情补充。
